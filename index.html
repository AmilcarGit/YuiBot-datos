Conecta tu bot

Si instalas YuiBot-MD, ya viene apuntando a este servicio. Estos pasos son para usar tu propia copia del servidor.

  1. Despliega este repositorio en Vercel y conecta una base Upstash Redis desde Storage.

  2. Agrega la variable DATOS_PEPPER con un texto largo y aleatorio, y vuelve a desplegar. No la cambies después.

  3. En el .env de tu bot pon esta línea y reinícialo:

    SYNC_URL=

  4. Comprueba con .sincronizar estado y .topglobal en WhatsApp.

Preguntas frecuentes

¿Se guardan los números de teléfono?

No. Cada número se convierte en un código irreversible antes de guardarse, y el ranking solo muestra el principio y el final (por ejemplo 519•••479).

¿Qué pasa si este servicio se cae?

Nada grave: el bot sigue funcionando con sus datos locales, espacia los reintentos y vuelve a sincronizar cuando el servicio responda. No se pierde lo que ganaron los usuarios mientras tanto.

¿Qué datos se comparten?

Monedas, XP, nivel, mensajes, reputación, logros, inventario, trabajos y mejoras. Las monedas, la XP y las ganancias se suman entre instalaciones; las mejoras y rachas conservan el mayor valor.

¿Se puede hacer trampa?

El servidor valida cada sincronización y pone topes por sincronización y por hora, y las instalaciones sospechosas se pueden bloquear. Un bot modificado puede intentar mentir dentro de esos topes, pero no fabricar millones.
