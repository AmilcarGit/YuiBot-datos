Cómo empezar

Elige el camino que te sirva. Tu progreso se guarda solo en cuanto uses el bot.

1 Usa un bot que ya existe

Si estás en un grupo con YuiBot-MD, escribe estos comandos. En unos 2 minutos aparecerás aquí al buscar tu número.

.menuTodo lo que puede hacer el bot
.regTe registras (nombre, género y edad)
.perfilTu tarjeta con nivel y monedas
.trabajosFormas de ganar monedas
.topglobalEl ranking mundial

2 Instala tu propio bot

En Android con Termux (gratis). Necesitas un número de WhatsApp para vincularlo.

pkg update && pkg upgrade pkg install nodejs git ffmpeg yt-dlp git clone https://github.com/AmilcarGit/YuiBot-MD.git cd YuiBot-MD npm install npm start

Ya viene conectado a esta base de datos: tus monedas y nivel serán los mismos que en cualquier otro bot.

Administración (solo dueños del servidor)

Necesitas la variable ADMIN_TOKEN de tu proyecto en Vercel. Se usa solo en esta pestaña: no se guarda en ningún sitio.

Zona de peligro

Borra los datos de todos los jugadores del servidor (rankings, perfiles y gráficas). Las instalaciones siguen registradas y cada bot vuelve a subir sus datos limpios en unos minutos. Escribe REINICIAR para confirmar.

Usar mi propio servidor

1) Despliega el repositorio en Vercel y conecta una base Upstash Redis (Storage). 2) Agrega la variable DATOS_PEPPER con un texto largo y aleatorio y vuelve a desplegar. 3) En el .env de tu bot pon:

SYNC_URL=

Comprueba con .sincronizar estado en WhatsApp.

Preguntas frecuentes

No aparezco al buscar mi número

Revisa que lo escribas con código de país y solo dígitos (ej. 51910227479). Si ya usas el bot, espera unos 2 minutos: el bot sincroniza en segundo plano. Si nunca lo has usado, escribe .perfil en un grupo con el bot para empezar.

¿Se guardan mi número y mis datos personales?

Tu número no se guarda: se convierte en un código irreversible. Esta página solo muestra datos de juego (nivel, monedas, XP, logros, trabajos y puestos); nunca tu nombre, edad ni género. En los rankings tu número aparece enmascarado.

¿Qué pasa si esta página o la API se caen?

Nada grave: el bot sigue funcionando con sus datos locales, espacia los reintentos y vuelve a sincronizar cuando el servicio responda. No se pierde lo que ganaste mientras tanto.

¿Por qué mis monedas tardan en actualizarse?

Los bots sincronizan cada 2 minutos y esta página se refresca cada 15 segundos. Si acabas de ganar monedas, espera un poco y vuelve a buscar.

¿Se puede hacer trampa?

El servidor valida cada sincronización, pone topes por sincronización y por hora, y las instalaciones sospechosas se bloquean. Un bot modificado puede intentarlo, pero no fabricar millones.

¿Cómo dejo de compartir mis datos?

Quien administra el bot puede apagar la sincronización con SYNC_ENABLED=false en su .env. Si quieres que se borren tus datos de la base compartida, pídeselo al creador del bot.
